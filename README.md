# TaskFlow

Aplicação de console desenvolvida em C# com .NET 10 para gerenciar tarefas.

## Funcionalidades

- Adicionar tarefas.
- Listar tarefas.
- Concluir tarefas.
- Buscar tarefas por ID.
- Validar títulos vazios ou nulos.

## Requisitos

- .NET 10 SDK.

## Como compilar

```bash
dotnet build
```

## Como executar

```bash
dotnet run --project TaskFlow.Console/TaskFlow.Console.csproj
```

## Como executar os testes

```bash
dotnet test
```

## Tecnologias

- C#
- .NET 10
- xUnit
- Git
